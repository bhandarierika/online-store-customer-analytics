# Online Store Customer Analytics Dashboard

An interactive Microsoft Excel project analysing customer behaviour and Premium subscription patterns using a synthetic online store dataset.

## Project Overview

The objective of this project is to understand customer characteristics, shopping behaviour and Premium membership adoption. The project uses Excel data-cleaning techniques, Pivot Tables, Pivot Charts, KPI cards and interactive slicers.

**Dataset:** Synthetic data created for analytical practice.

## Business Questions

- What percentage of customers subscribe to Premium?
- How does Premium subscription vary across age groups?
- Which income bands have higher Premium subscription rates?
- Does subscription behaviour differ by shopping device?
- How does average monthly income compare between Premium and non-Premium customers?

## Tools and Techniques

- Microsoft Excel
- Data cleaning and validation
- IF formulas and conditional logic
- Pivot Tables and Pivot Charts
- GETPIVOTDATA
- KPI cards
- Interactive slicers and Report Connections
- Dashboard design

## Dashboard Features

- 3 KPI cards
- 5 analytical charts
- 3 interactive slicers:
  - Device
  - Age Bracket
  - Income Band

## Key Findings

- Total customers: 1,000
- Premium subscribers: 363 (36.30%)
- High-income Premium subscription rate: 56.85%
- Low-income Premium subscription rate: 17.90%
- Mobile Premium subscription rate: 38.83%
- Average monthly income of Premium subscribers: ₹70,687.68
- Average monthly income of non-Premium subscribers: ₹46,807.50

## Data Cleaning

- Checked customer records for duplicates.
- Audited categorical values for inconsistencies.
- Identified 38 missing monthly income values.
- Identified 15 missing education values.
- Classified six invalid ages as Review.
- Excluded invalid-age records from valid age-group analysis while retaining them in the overall dataset.

## Business Recommendations

1. Investigate differences in Premium adoption across income segments.
2. Test targeted membership offers and measure conversion rates.
3. Evaluate the mobile shopping experience.
4. Explore customer retention opportunities among Premium subscribers.
5. Monitor missing and invalid data to improve data quality.

## Limitations

- The dataset is synthetic and intended for practice.
- Findings describe associations, not causal relationships.
- Missing income values may affect income-based comparisons.
- Invalid ages were excluded from age-group analysis.

## Project Outcome

Developed an interactive Excel dashboard to explore customer segments and Premium subscription behaviour through KPI cards, Pivot Charts and slicers.
